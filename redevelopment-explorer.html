Parcel type

Vacant = coded vacant by the assessor, or carrying land value with no building value. Underused = a built parcel whose appraised building value is low relative to its appraised land value (loaded on first use). Condominium units, cemeteries, roads and water are left out.

General zoning (mapped)

Each town's zoning districts are grouped into these general classes from the district code and description. Click anywhere on the map to see the exact district.

How the assessor codes vacant land

Towns code vacant land differently, so each vacant parcel is sorted by its assessor use code and description. Pick a town to see how that assessor's parcels fall. “Not coded vacant” means the record has land value and no building value but no vacant-land code.
